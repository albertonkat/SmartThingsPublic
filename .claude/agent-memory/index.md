## How to Use
```bash
# Search all consolidated memory
.claude/hooks/memory-tool.sh search "<keyword>"

# List recent entries
.claude/hooks/memory-tool.sh recent 20

# List all consolidated files
.claude/hooks/memory-tool.sh list
```
